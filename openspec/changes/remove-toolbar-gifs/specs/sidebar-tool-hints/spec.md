# Spec Delta

## Purpose

侧边栏工具提示用于在用户悬停工具时说明该工具的名称、用途、快捷键和可用操作。提示应以文字呈现，不依赖教程 GIF，使演示页与浏览器扩展中的使用体验保持一致。

## ADDED Requirements

### Requirement: 侧边栏工具提示仅呈现文字
系统 SHALL 在侧边栏工具的现有悬浮提示中保留工具名称、快捷键及已有的说明和操作文字，不呈现或请求教程 GIF。

#### Scenario: 悬停有操作说明的工具
- **WHEN** 用户悬停带有操作说明的侧边栏工具
- **THEN** 提示显示该工具的名称、快捷键及已有的说明和操作文字，且不包含 GIF 图像

#### Scenario: 悬停无操作说明的工具
- **WHEN** 用户悬停没有额外操作说明的侧边栏工具
- **THEN** 提示仍显示工具名称、快捷键及已有的说明，且不包含 GIF 图像
