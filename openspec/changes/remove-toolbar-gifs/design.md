# Design

## Context

见 `proposal.md`。工具栏的 `demoTip()` 同时渲染教程 GIF 和文字；扩展注入脚本提供 GIF 路径，构建与打包脚本复制 `tuts/`，演示页的分享元数据也引用 GIF。`sidebar-tool-hints` 规范要求保留现有文字提示。

## Goals / Non-Goals

**Goals:** 让演示页和扩展的侧边栏只显示现有文字提示，并使删除 GIF 后的构建与分享元数据仍有效。

**Non-Goals:** 不重设计提示样式，不改写工具说明或快捷键，不删除 PNG/SVG 等其他图片。

## Decisions

1. 在现有提示模板中只移除 `<img>` 和教程路径属性，保留 `<aside>`、`<figure>`、`<figcaption>` 与文字节点。这样可沿用现有悬停、定位和顶层显示逻辑。替代方案是删除整个提示组件，但会丢失用户明确要求保留的文字。
2. 删除两处教程 GIF 目录及扩展侧的复制、打包和资源声明；同步移除注入脚本设置教程路径的代码。替代方案是保留未使用的 GIF 和复制逻辑，但与“删除 GIF 文件”的要求不符，还会留下无效依赖。
3. 演示页的 Open Graph/Twitter 预览图改指向已有的 `app/assets/visbug.png`。替代方案是移除预览图字段，但会使页面分享失去已有的图像预览。

## Risks / Trade-offs

- [图片移除后提示尺寸改变] → 检查现有文字布局，只有实际出现布局问题时才调整对应 CSS。
- [构建脚本仍引用已删目录] → 运行扩展构建与打包，检查产物不再包含教程 GIF 路径。
